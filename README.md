# Test Vocacional — PMV

Producto Mínimo Viable del proyecto **“Te guiaremos a tu futuro”**.

## Objetivo
Ofrecer una versión sencilla y funcional de un test vocacional para estudiantes de secundaria, permitiendo responder preguntas, procesar las respuestas y mostrar áreas profesionales de mayor afinidad.

## Funcionalidades
- Página de inicio.
- Registro de nombre, edad y grado.
- Test de 25 preguntas.
- Barra de progreso.
- Validación de respuesta antes de avanzar.
- Cálculo de resultados por áreas.
- Resultado personalizado.
- Posibilidad de repetir el test.
- Guardado local de datos y resultado.
- Diseño adaptable a celular y computadora.

## Áreas evaluadas
- Tecnología e ingeniería.
- Creatividad y comunicación.
- Ciencias sociales y ayuda.
- Negocios y gestión.

## Tecnologías
HTML5, CSS3 y JavaScript puro. No requiere servidor ni base de datos para funcionar.

## Nota
Este PMV es una versión básica de validación del proyecto. No reemplaza una evaluación vocacional profesional.
